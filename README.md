# 🌿 Cozy Focus Dashboard

A beautiful and minimal desktop productivity application designed to help users stay focused, organize daily tasks, and track their productivity.

Built using **React, Vite, and Electron.js**.

## ✨ Features

- **Focus Timer** – Stay focused using a dedicated focus timer.
- **Task Management** – Organize and manage your daily tasks.
- **Progress Tracking** – Monitor your productivity and progress.
- **Motivation Card** – Stay motivated throughout your day.
- **Quick Shortcuts** – Access useful actions quickly.
- **Desktop Application** – Use the dashboard as a standalone Windows application.

## 🛠️ Technologies Used

- React.js
- Vite
- Electron.js
- JavaScript
- CSS
- Lucide React

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/MehalJain21/cozy-focus-dashboard.git
```

### 2. Navigate to the project

```bash
cd cozy-focus-dashboard
```

### 3. Install dependencies

```bash
npm install
```

### 4. Build the Windows application

```bash
npm run electron:build
```

## 🖥️ Desktop Application

Cozy Focus Dashboard is packaged as a Windows desktop application using Electron.js.
